# VaniRakshak UI Design System

## Overview
- Dark theme
- Geist font
- Tailwind v4

## Dashboard Layout
- Scrolly video pipeline explainer
- Console with risk meter
- Forensic benchmark suite
- Forensic verdict card
- Waveform evidence timeline

## Color Palette
Risk tiers mapped to colors:
- Green = ALLOW
- Amber = CHALLENGE
- Red = BLOCK

## Component Architecture
- `ScrollyVideoCanvas`
- `DemoQuickSelector`
- `AudioUploadZone`
- `ForensicVerdictCard`
- `WaveformEvidenceTimeline`

## Interlock UI States
- Normal
- Challenge active
- Transaction locked

## Real-time Streaming UI
- Audio level meter
- Live event log
- Risk score gauge
