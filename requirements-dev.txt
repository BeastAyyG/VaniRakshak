# VaniRakshak - development and test environment
#
# Why this file exists: the repo previously had no single manifest that could
# bootstrap it. Dependencies were split across backend/requirements.txt,
# ml/requirements.txt and vanirakshak-backend/requirements.txt, and NONE of them
# included pytest -- so `make test` (which runs bare `pytest`) could never work
# on a clean checkout.
#
# This manifest installs enough to run `pytest` (15 tests, pytest.ini's
# testpaths = vanirakshak-backend/tests) and to boot the one live backend
# (vanirakshak-backend/). It does NOT by itself cover the root-level tests/
# directory (18 more tests, the ASR stack) -- that additionally needs `groq`
# and `python-dotenv` from the root requirements.txt, which `make setup` does
# not install. Run `pip install -r requirements.txt` too if you're touching
# backend/services/asr/ or vanirakshak/semantic/.
#
#   pip install -r requirements-dev.txt
#
# torch/torchaudio are large. The CPU wheels keep it to roughly 200 MB and are
# what `make setup` uses:
#
#   pip install -r requirements-dev.txt \
#       --extra-index-url https://download.pytorch.org/whl/cpu
